# Storage and persistence

> **Central question:** What survives beyond a worker’s memory or lifetime?

This category examines storage and persistence through the lens of LLM inference and serving engines.

## Scope

Shared block storage, metadata indexes, durability, replication, erasure coding, retention, GC.

## Learning objectives

- Separate transient serving state from durable stored state.
- Reason about metadata, replication, retention, and garbage collection.
- Describe recovery requirements when a worker or storage component fails.
